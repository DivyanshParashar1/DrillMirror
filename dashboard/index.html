How It Works

  1. Ingest — parquet time series from the 3W dataset are summarized into instance-level features.
  2. Detect — an Isolation Forest scores each instance for anomaly likelihood.
  3. Explain — the ontology graph maps flagged sensors to equipment and candidate event types.
  4. Report — LLM-backed chatbot generates Manager and Engineer-facing summaries.
